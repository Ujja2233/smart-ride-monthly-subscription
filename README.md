# 🚗 Smart Ride

### Monthly Pickup & Drop Subscription Platform

Smart Ride is a frontend web application that makes daily transportation easier through monthly pickup and drop subscription plans.

## Features
- Monthly ride subscription plans
- Easy booking form
- User dashboard
- Driver dashboard
- Vehicle owner dashboard
- Management dashboard
- Admin dashboard
- Responsive design
- LocalStorage booking management

## Technologies
- HTML5
- CSS3
- JavaScript

## Subscription Plans
- Weekday Essential – ₹3,999/month
- Smart Flex – ₹4,999/month
- Premium Plus – ₹6,999/month

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
